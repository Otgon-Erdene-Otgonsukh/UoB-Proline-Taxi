## Testing Day User Feedback (2nd of February 2026)
The following are the feedback and suggestions that were provided by the users who tested our app. The feedback is divided into their suitable categories regarding front-end/UI and backend/API.

### UI/UX
 - The user can press enter to register the location to show up in the map rather than clicking away to display.
 - The validation errors clear when user retypes in the text fields to prevent false errors.
 - The Via toggle should be a plus button rather than a toggle and conveniently placed.
 - The Information cards in department dashboard page can be interactible filters that is applied when clicked.
 - Modify Navbar logos to stack the university and proline taxi logos to declutter the navbar.
 - Disable the "Manually Enter" toggle in booking page when Flight toggle is on rather than removing it.
 - Make Navbar sticky to persist on scrolls.
 - Make About page step icons to be buttons that naviagtes to their specific resource.
 
### Backend / API
 - Autofill passenger detail feature in booking form if the user is making a booking for themselves. (Could be a "Book for myself" button)
 - Server / Client side validation on passenger count field in booking page.
 - When editing personal details in profile page, prompt the user to enter their password.
 - The post codes used for locating pick up and drop off locations should be converted into their names when booking is created.
 - Passenger Name search not working bug.
